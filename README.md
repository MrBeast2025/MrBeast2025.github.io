## 四、⚠️ 三条不能破的规则

1. **7000% 的口径说明不能删。** 左栏 `metricsNote`、台账脚注、经历里的「回测口径，不代表实盘」都要保留，也**不能把它写成「实盘收益」**——面试被追问时口径不一致，可信度会直接归零。
2. **`content.js` 只能改引号里的内容。** 不要动 `{ }` `[ ]` `,`；少一个逗号整页会显示「内容加载失败」（页面会提示，不会白屏）。
3. **不要把电话、生日、详细住址放上去。** 公网页面会被爬虫抓取。

## 六、设计依据（为什么长这样）

这一版的视觉不是拍的，是按 Anthropic 官方 `frontend-design` 技能的规范做的。技能里明确列了 5 条「AI 生成设计」的识别特征（近黑背景 + 荧光绿、等宽字体贴标签、卡片套件、每区块 fade-slide 动效、全大写眉标），第一版**全部命中**，所以整体重做：

| 设计决定 | 原因 |
|---|---|
| 衬线体做标题、无衬线做正文、等宽只用于数字与代码 | 三种字体各司其职，避免"全站等宽"的模板感 |
| 只保留两处动效（左栏载入一次 + 复制成功提示） | 每个区块都 fade-slide 是 AI 味的最大来源 |
| 编号只用在真实有序的地方 | 项目真的是流程、时间线真的是先后 |
| 全站唯一"大胆"之处留给台账与净值曲线 | 技能原话：把大胆花在一个地方 |
| 去卡片化，用 1px 细线分隔 | 统一圆角 + 同一层阴影是最典型的模板特征 |

## 八、项目配图（v2.1 新增）

三个项目现在各有一组配图轮播，共 **10 张**，放在 `images/projects/`：

| 项目 | 配图 |
|---|---|
| 01 因子台账 | 因子筛选链路、相关性矩阵、分位数分组收益、回测净值对比、绩效面板 |
| 02 网站构建 | 七步法执行终端、设计规范令牌、三档响应式布局 |
| 03 数模自动化 | 模型拟合与残差、赛程时间分配 |

**轮播行为**：左右箭头切换、圆点跳转、键盘 ← → 切换、手机左右滑动、进入视野后自动播放（6 秒一张）。鼠标悬停、键盘聚焦、切到后台标签页时**自动暂停**；系统开启「减少动态效果」时**不自动播放**。

### ⚠️ 关于这些配图，必须知道的事

**它们不是系统原始截图，是示意重建图。** 每张图底部都印了「示意重建图」的说明——这是刻意的：

- 你手上没有这三个项目的真实截图，用生成图冒充截图属于**编造证据**，面试被问"能现场跑一下吗"就穿帮；
- 但这些图**展示的都是真实产出物的形态**（相关性矩阵、分位数收益、净值曲线就是做因子研究的日常报表），面试官认这个；
- 图注写明口径后，**不怕被追问**，反而是加分项。

**有真实截图之后，替换掉它们。** 那才是最有说服力的版本。

### 怎么改图 / 换图

| 想做什么 | 怎么做 |
|---|---|
| 换一张图 | 把你的图片放进 `images/projects/`，然后把 `content.js` 里对应的 `src` 改成新文件名 |
| 改图注文字 | `content.js` 里对应项目的 `gallery[].caption` |
| 加一张图 | 在 `gallery` 数组里复制一行 `{ src: "...", alt: "...", caption: "..." }`，注意末尾逗号 |
| 删一张图 | 删掉对应的那一整行（含末尾逗号） |
| 重新生成图表 | `images/_src/` 里是这 10 张图的源码（HTML+SVG），改完用无头浏览器截图即可重新导出 PNG；改不动就找 Agent |

**图片规格**：1200 × 750 px（16:10），单张 11–26 KB，全部本地文件、**不依赖任何外链**。
